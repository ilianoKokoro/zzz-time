# ZZZ Time

<img src="https://raw.githubusercontent.com/ilianoKokoro/zzz-time/main/app-icon.png" height="72">

A lightweight **Windows shutdown scheduler** built with **Tauri**, **Vue** and **shadcn-vue**.

Designed to be simple and fast, ZZZ Time lets you schedule automatic PC shutdowns with a clean and minimal interface.

## Features ✨

- Schedule Windows shutdowns
- Minimal and lightweight
- Automatic dark mode support
- Standalone and Installed versions
